# Dataset

## Dataset Source

The dataset used in this project was obtained from the **University of Queensland (UQ) eSpace repository, Australia**.

**Institution:** The University of Queensland, Australia

**Repository:** UQ eSpace

**Record:** UQ:5d0832d

**Source:** https://espace.library.uq.edu.au/view/UQ:5d0832d

## Purpose

The dataset is used in this project for **Network Intrusion Detection**, including:

* Network traffic analysis
* Data preprocessing
* Feature engineering
* Feature selection
* Machine Learning model development
* Intrusion classification
* Model evaluation

## Dataset Usage

The original dataset is not included directly in this GitHub repository.

To reproduce the project:

1. Access the dataset through the University of Queensland eSpace repository.
2. Download the required dataset files.
3. Place the dataset inside this `data/` directory.
4. Run the analysis notebook:

```text
notebooks/NIDS_Analysis.ipynb
```

## Important Features

The project uses network traffic features such as:

* Flow Duration
* Packet Count
* Source Bytes
* Destination Bytes
* SYN Count
* Other relevant network-flow features available in the dataset.

## Reproducibility

The preprocessing, feature engineering, model training, and evaluation procedures are implemented in the project notebook.

Users reproducing the project should obtain the dataset from the original source and follow the processing pipeline provided in the notebook.
